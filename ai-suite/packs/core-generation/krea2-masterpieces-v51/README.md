# Krea2 Masterpieces v51 (Krea2 LoRA)

Standalone preset for the krea2-masterpieces-v51 quality/style LoRA, applied over the Moody Cutie Mix Krea2 v2.0 checkpoint.

- Base checkpoint: `moodyCutieMixKrea2_v20.safetensors` (diffusion_models/)
- LoRA: `krea2-masterpieces-v51.safetensors` (loras/), default strength 0.8
- Text encoder: `qwen3vl_4b_fp8_scaled.safetensors` (text_encoders/)
- VAE: `qwen_image_vae.safetensors` (vae/)
