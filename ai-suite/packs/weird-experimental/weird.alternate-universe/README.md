# Alternate Universe

Transforms any input into a vivid alternate universe with unique physics, colors, and reality.

## Overview

Create breathtaking alternate realities:

- **Physics Defiance**: Gravity, time, and space behave differently
- **Alien Colors**: Unnatural but beautiful color palettes
- **Reality Bending**: Impossible architecture and landscapes
- **Atmospheric Effects**: Unique lighting and weather systems

## Presets

### Subtle
- Light reality shift (0.5)
- Gentle color changes
- Subtle physics distortion

### Extreme
- Heavy reality shift (0.9)
- Dramatic color transformations
- Extreme physics bending
