# Corporate Nightmare

Creates a corporate branding nightmare - applying excessive branding, awkward fonts, and corporate clichés to any input.

## Overview

Transform any image or concept into a dystopian corporate presentation:

- **Excessive Branding**: Multiple overlapping logos and branding elements
- **Awkward Typography**: Corporate sans-serif fonts with awkward layouts
- **Cliché Color Schemes**: Corporate blue, energy orange, eco-green palettes
- **Saturating Overlays**: Infographics, charts, and data visualizations everywhere

## Presets

### Subtle
- Light branding effect (0.6 intensity)
- Minimal logo count (2-3)
- Standard corporate typography

### Extreme
- Heavy branding (0.9 intensity)
- Maximum logos (10-15)
- Aggressive typography styles
- Saturating color schemes
