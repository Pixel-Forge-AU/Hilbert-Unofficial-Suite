Genesis Runtime

Genesis Runtime is a standalone plugin-host runtime, independent of the Planner/Orchestrator/ OpenHands build pipeline. It ships with zero plugins enabled by default - infrastructure only, no built-in agents, chat, or memory. Behavior comes entirely from whatever plugins it's pointed at.

Genesis: Open

Start runs agent-switch genesis, which launches genesis-runtime/server.js on the host/port set by GENESIS_HOST / GENESIS_PORT in the agent suite's config.env (default 0.0.0.0:39008). Stop kills it. Genesis: Open loads its minimal status page, listing runtime status and installed plugins. Status refreshes the shared status panel for every suite service, not just Genesis.

With no further config, Start gives you a clean boot with 0 plugins and 0 capabilities - there's nothing to do with it yet. To make it useful: set GENESIS_PLUGIN_DIR in the agent suite's config.env to point at a plugin catalog (11 ship in genesis-runtime/plugins/: secrets, model-provider, home-assistant, memory, retrieval, sandbox, skills-marketplace, voice-avatar, workspace, mail, agent-runtime), and set GENESIS_PROFILE to choose which plugins are enabled - minimal, personal-assistant, developer, full, default, or 3dpb-business (see genesis-runtime/profiles/). Plugins outside this repo's own plugins/ directory need to be on a hash allowlist unless you set GENESIS_EXTERNAL_PLUGIN_IMPORT_MODE=permissive for a trusted directory. See genesis-runtime/README.md for the full picture. 

Use Start to launch Genesis Runtime. Status shows every suite service.
